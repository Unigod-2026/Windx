# 风球GEO监控前端UI - 项目记忆

## 项目概述
风球科技 GEO 监控平台前端 UI 设计与原型开发。监控 7 大国内主流大模型（豆包、元宝、通义千问、Kimi、DeepSeek、文心一言、蚂蚁阿福）对品牌的提及情况。

## 技术栈
- 纯 HTML/CSS/JS，无框架依赖
- 图表：纯手写 SVG 引擎
- 设计规范：腾讯 TDesign
- 品牌色：蓝 #1a55e8 + 橙 #ff6b1a（WINDx Logo）

## 页面结构
1. 登录页（左品牌展示 + 右登录卡片）
2. Tab1 首屏概览（KPI 卡片 + 折线趋势 + 排行 + 告警）
3. Tab2 问题提及分析（左列表右详情分屏 + 模型对比 + AI原文 + 下钻）
4. Tab3 竞品分析（趋势对比 + 标签云 + 竞争优势矩阵）
5. Tab4 信源偏好（7类分类 + 按模型细分 + 稳定信源 + 优化建议）
6. Tab5 引用源分析（URL/标题/DR/流量/引用次数/排名位置）
7. AI回答详情页（7模型并排对比 + 命中率高亮）
8. 问题管理 / 竞品管理 / 设置

## 用户偏好
- 商务简约风格，平面化图标
- 参考 Semrush UI
- 左侧主导航 + 顶部二级 Tab
- 全局搜索 Ctrl+K
- 快捷键：Q(新建问题) K(关键词) P(项目) E(导出) W(周报)
- 分辨率：2K+ 适配
